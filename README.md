Glossário:

SGBD: Sistema de Gerenciamento de Bancos de Dados.

SQL: Structured Query Language ou Linguagem de Consulta Estruturada.

ACID: são os quatro princípios garantidores da integridade e confiabilidade das transações em sistemas de bancos de dados, sendo esses:

Atomicidade: Garante que cada transação seja tratada como uma unidade única, assim, todas operação são completadas ou não completadas.

Consistência: Evita a corrupção dos dados garantindo que o banco de dados transite apenas entre estados consistentes.

Isolamento: Não permite a interação entre os dados, garantindo a atomicidade.

Durabilidade: Assegura a segurança dos dados mesmo diante as falhas, garantindo o armazenamento correto das transações.

NoSQL: São bancos de dados criados para armazenar grandes volumes de dados sem necessariamente estar em uma estrutura fixa.

RDBMS: Relational Database Management System ou Sistema Gerenciador de Banco de Dados Relacionais; por ser RELACIONAL atua com o uso de tabelas formadas por tuplas e atributos (linhas e colunas).

Chave-Primária (primary-key): é um atributo ou conjunto deles que são únicos, como um CPF que não pode se repetir, ou um numero de identificação único de cada usuário.

Chave-Estrangeira (foreign-key): é o atributo que relaciona as tabelas com dados comuns entre elas, conectando os dados e referenciado com chaves primárias.
